# WorkTracking

The WorkTracking context helps a person record small pieces of work and carry each one to completion.

## Language

**Work item**:
A specific piece of work that a person intends to complete.
_Avoid_: Task, ticket, todo

**Title**:
The short, meaningful name of a work item.
_Avoid_: Description, label, summary

**Open work item**:
A work item that has not been completed.
_Avoid_: Active, pending, incomplete

**Completion**:
The successful act that changes an open work item into a completed work item.
_Avoid_: Close, resolve, archive

**Completed work item**:
A work item for which completion has occurred.
_Avoid_: Closed, resolved, archived
